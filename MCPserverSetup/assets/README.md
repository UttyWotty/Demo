# Screenshots & Assets

Add screenshots here after running the demo:

1. **api_docs.png** - Screenshot of http://localhost:8000/docs
2. **dashboard.png** - Screenshot of the Streamlit dashboard
3. **modules.png** - Screenshot showing the multi-module support

## How to Take Screenshots

### API Documentation
1. Run: `python demo_mcp_server.py`
2. Open: http://localhost:8000/docs
3. Take full-width screenshot
4. Save as: `api_docs.png`

### Dashboard (if implementing)
1. Run: `streamlit run demo_dashboard.py`
2. Open the dashboard
3. Take full-width screenshot
4. Save as: `dashboard.png`

### Module Support
1. Use `/api/modules` endpoint response
2. Screenshot the JSON output or create a diagram
3. Save as: `modules.png`

## Tips for Good Screenshots

- Use full browser width
- Clear browser address bar and bookmarks if needed
- Ensure good contrast and readability
- Capture key features and UI elements
- Consider adding annotations/highlights for key features
